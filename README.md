# Vision

Xây dựng một hệ sinh thái website sử dụng AI làm trung tâm, tập trung vào:

- AI Tools
- Programmatic SEO
- Affiliate Marketing
- Display Ads
- AI Search
- RAG Knowledge Base

Mục tiêu là tạo nhiều nguồn traffic organic và nhiều nguồn doanh thu trên cùng một nền tảng.
